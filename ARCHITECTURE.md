# DomasPad -- Complete Build Specification

This document is a self-contained specification for building DomasPad from scratch. A developer (or AI assistant) should be able to reproduce the entire application using only this document.

---

## 1. What Is DomasPad

A lightweight Notepad++ alternative for macOS. A tabbed text editor with syntax highlighting, auto-saved sessions, dark/light themes, and Finder integration. Built with Electron (main + renderer process) and CodeMirror 6 (editor). No frameworks -- plain HTML/CSS/JS in the renderer.

|------|-------|

### IPC Handlers (ipcMain.handle)

| Channel | Direction | Input | Output | Purpose |
|---------|-----------|-------|--------|---------|
| `session:load` | renderer->main | none | session object | Read session.json from disk |
| `session:save` | renderer->main | `{tabs, activeTabId, theme}` | none | Write session.json to disk |
| `dialog:save-as` | renderer->main | defaultName string | filePath or null | Native Save dialog |
| `file:save-to-disk` | renderer->main | `{filePath, content}` | boolean | Write file to disk |
| `file:read` | renderer->main | filePath string | content string or null | Read file from disk |

### Menu-Triggered Events (mainWindow.webContents.send)

| Channel | Payload | Trigger |
|---------|---------|---------|
| `menu:new-tab` | none | Cmd+T |
| `menu:close-tab` | none | Cmd+W |
| `menu:save-as` | none | Cmd+Shift+S |
| `menu:find` | none | Cmd+F |
| `menu:set-theme` | `"dark"` or `"light"` | Cmd+Shift+D / Cmd+Shift+L |
| `file:opened` | `{filePath, content}` | Cmd+O or Finder open-file |

### Finder / "Open With" Integration

Three mechanisms for opening files externally:

1. **`app.on('open-file')`** -- macOS sends this when user does "Open With" in Finder, drags file to dock icon, or double-clicks an associated file. The handler reads the file and sends `file:opened` to the renderer. If the window isn't ready yet, the path is queued in a `pendingFiles` array and sent on `did-finish-load`.

2. **Command-line arguments** -- On first launch, `process.argv` is scanned for file paths (skipping electron binary and flags). Each valid file is opened as a tab.

3. **`app.on('second-instance')`** -- If the app is already running and launched again with files, the existing window is focused and the new files are opened. Requires `app.requestSingleInstanceLock()`.

### Session File
Location: `~/Library/Application Support/DomasPad/session.json` (derived from `app.getPath('userData')`).

### Window State Persistence
On `close` event, window bounds `{x, y, width, height}` are saved into session.json under the `window` key. On next launch, the window is created at the saved position/size.

## 5. Preload Bridge (preload.js)

Uses `contextBridge.exposeInMainWorld('api', {...})` to expose exactly these methods to the renderer:

```js
window.api = {
  // Invoke (async, returns promise)
  loadSession()                        // -> session object
  saveSession(data)                    // -> void
  saveAs(defaultName)                  // -> filePath or null
  saveToDisk(filePath, content)        // -> boolean
  readFile(filePath)                   // -> string or null

  // Listen (callback registration)
  onNewTab(callback)
  onCloseTab(callback)
  onSaveAs(callback)
  onFind(callback)
  onFileOpened(callback)               // callback receives {filePath, content}
  onSetTheme(callback)                 // callback receives "dark" or "light"
}
```

## 7. Renderer Application Logic (renderer/app.js)

### Imports
```js
import { EditorView, basicSetup } from 'codemirror';
import { EditorState, Compartment } from '@codemirror/state';
import { oneDark } from '@codemirror/theme-one-dark';
import { openSearchPanel } from '@codemirror/search';
// + language imports: javascript, html, css, json, python, markdown, sql, java, cpp, xml
```

### Global State
```js
let tabs = [];              // array of tab objects
let activeTabId = null;     // id of currently visible tab
let editorView = null;      // single CodeMirror instance, recreated on tab switch
let saveTimeout = null;     // debounce timer for auto-save
let currentTheme = 'dark';  // "dark" or "light"
const themeCompartment = new Compartment();  // for runtime theme swapping in CM
```

### Tab Object Shape
```js
{
  id: string,           // unique, generated as Date.now().toString(36) + random
  name: string,         // display name: filename or "Untitled-N"
  content: string,      // full text content
  filePath: string|null, // absolute path for file-backed tabs, null for scratch
  cursorPos: number      // character offset for cursor restoration
}
```

### Language Detection (LANG_MAP)

Maps file extension to `{ext: languageFunction, name: displayString}`:

| Extensions | Language Function | Display Name |
|------------|------------------|--------------|
| js, mjs | `javascript()` | JavaScript |
| jsx | `javascript({jsx: true})` | JSX |
| ts | `javascript({typescript: true})` | TypeScript |
| tsx | `javascript({jsx: true, typescript: true})` | TSX |
| html, htm | `html()` | HTML |
| css, scss | `css()` | CSS |
| json | `json()` | JSON |
| py | `python()` | Python |
| md | `markdown()` | Markdown |
| sql | `sql()` | SQL |
| java | `java()` | Java |
| c, cpp, h | `cpp()` | C / C++ |
| xml, svg | `xml()` | XML |
| yaml, yml, txt, sh, bash, zsh | null (no highlighting) | Plain Text / YAML / Shell |

### Editor Creation

Only **one CodeMirror instance** exists at a time. When the user switches tabs:

1. Save the current tab's cursor position
2. Destroy the existing `EditorView`
3. Create a new `EditorState` with:
   - `basicSetup` (line numbers, bracket matching, etc.)
   - `themeCompartment.of(currentTheme === 'dark' ? oneDark : [])` -- empty array = default light
   - `EditorView.lineWrapping`
   - `EditorView.updateListener` to track content changes and cursor position
   - Language extension based on file name
   - `selection: { anchor: cursorPos }` to restore cursor
4. Create new `EditorView` mounted in `#editor-container`
5. Call `editorView.focus()`

### Auto-Save Flow

```
EditorView.updateListener fires on docChanged
  -> tab.content = editor text
  -> scheduleSave() clears/sets 300ms timeout
  -> saveSession() sends {tabs, activeTabId, theme} via window.api.saveSession()
  -> main process merges into session.json and writes to disk
```

### Session Restore Flow (on app launch)

```
restoreSession()
  -> window.api.loadSession() returns session object
  -> if session.theme exists, call setTheme(theme)
  -> tabs[] = session.tabs
  -> for each file-backed tab, re-read from disk (window.api.readFile)
  -> renderTabs()
  -> switchTab(activeTabId)
```

If no session exists, create a single "Untitled-1" tab.

### Tab Operations

| Operation | Trigger | Behavior |
|-----------|---------|----------|
| Create tab | Cmd+T, "+" button, double-click empty tab bar | Push new tab to array, switch to it |
| Close tab | X button, middle-click, Cmd+W | Remove from array. If last tab, create "Untitled-1". If closing active tab, activate adjacent tab (prefer right, then left) |
| Switch tab | Click on tab | Set activeTabId, re-render tabs, recreate editor |
| Reorder | Drag and drop | Splice tab from old index, insert at drop target index |
| Close Others | Right-click context menu | Filter array to keep only target tab |
| Close to Right | Right-click context menu | Slice array at target index + 1 |
| Close to Left | Right-click context menu | Slice array from target index |
| Close All | Right-click context menu | Clear array, create "Untitled-1" |

### Tab Rendering (renderTabs)

For each tab, create a `<div class="tab">` (add `.active` class for active tab):
```html
<div class="tab active" draggable="true">
  <span class="tab-title">filename.js</span>
  <button class="tab-close">&#x2715;</button>
</div>
```

Event listeners per tab element:
- `click` -> switchTab
- `mousedown` (button === 1) -> closeTab (middle-click)
- `contextmenu` -> showTabContextMenu
- `dragstart` / `dragend` / `dragover` / `dragleave` / `drop` -> reorder

After rendering, `requestAnimationFrame` updates scroll button visibility and scrolls the active tab into view.

### Tab Context Menu

A `<div class="tab-context-menu">` is absolutely positioned at the right-click coordinates. Items:
- Close
- Close Others
- Close Tabs to the Right
- Close Tabs to the Left
- (separator)
- Close All

Dismissed on click outside via a `mousedown` listener on `document`.

### Tab Scroll Buttons

Two buttons (`#scroll-left-btn`, `#scroll-right-btn`) with class `.tab-scroll-btn`. They are `display: none` by default and get class `.visible` (which sets `display: flex`) when the tab container overflows. `updateScrollButtons()` checks `scrollWidth > clientWidth` and `scrollLeft` position.

Mouse wheel on `#tab-scroll-area` converts vertical scroll into horizontal (prevents page scroll, scrolls tabs instead).

### Theme Switching

```js
function setTheme(theme) {
  currentTheme = theme;
  document.documentElement.setAttribute('data-theme', theme);
  if (editorView) {
    editorView.dispatch({
      effects: themeCompartment.reconfigure(theme === 'dark' ? oneDark : [])
    });
  }
  scheduleSave();
}
```

Two layers:
1. `<html data-theme="dark|light">` toggles CSS custom properties for the shell UI
2. CodeMirror `Compartment.reconfigure()` swaps between `oneDark` and empty extension (default light)

### Status Bar

Updated on every cursor move and content change:
- Left: `Ln {line}, Col {col}` -- from `state.selection.main.head`
- Right: language display name from LANG_MAP

### Untitled Tab Naming

`getNextUntitledName()` finds the lowest N where `Untitled-N` doesn't exist in current tab names.

## 13. Critical Implementation Details

These details are easy to get wrong. Pay attention:

1. **esbuild is mandatory.** The renderer loads `bundle.js` as a plain `<script>`, NOT as `type="module"`. CodeMirror's ES module imports don't work with Electron's `file://` protocol. esbuild bundles everything into a single IIFE.

2. **Single CodeMirror instance.** Do NOT create multiple editors. Destroy and recreate on tab switch. This keeps memory low and avoids state sync bugs.

3. **Theme uses Compartment.** Import `Compartment` from `@codemirror/state`. Create one global `themeCompartment`. In `EditorState.create`, use `themeCompartment.of(oneDark)` for dark or `themeCompartment.of([])` for light. To switch at runtime, dispatch `themeCompartment.reconfigure(...)`.

4. **`open-file` event fires BEFORE `ready`.** Queue file paths in `pendingFiles[]` and flush them on `did-finish-load`. The `open-file` listener must be registered at the top level, before `app.whenReady()`.

5. **Single instance lock.** Call `app.requestSingleInstanceLock()` before creating the window. If another instance is launched, the `second-instance` event fires on the first instance with the new argv.

6. **Tab bar drag region.** The title bar needs `-webkit-app-region: drag` for window dragging, but tabs and buttons need `-webkit-app-region: no-drag`. Solution: a 72px drag div on the left (for traffic lights), a no-drag tab-bar in the middle, and a drag tail div on the right.

7. **Cursor position is a character offset**, not line:column. Store `state.selection.main.head` as an integer. Restore via `EditorState.create({ selection: { anchor: pos } })`.

8. **File-backed tabs re-read on restore.** When restoring a session, iterate tabs with `filePath !== null` and call `window.api.readFile(filePath)` to pick up external edits. Fall back to cached content if the file was deleted.

9. **Auto-save debounce is 300ms.** Clear and reset the timeout on every content change. This prevents disk thrashing during fast typing.

10. **The status bar displays language name** from LANG_MAP, not the file extension. Update it in `updateStatusBar()` which runs on every selection/content change.
