# DomasPad

A lightweight Notepad++ alternative for macOS, built with Electron and CodeMirror 6.

## Features

- **Tab System** — Create, close, reorder (drag & drop), middle-click to close, right-click context menu (Close Others, Close to Left/Right, Close All)
- **Syntax Highlighting** — JavaScript/TypeScript, HTML, CSS, JSON, Python, Java, C/C++, SQL, XML, Markdown, and more
- **Session Persistence** — All tabs, content, cursor positions, and window state are auto-saved and restored on relaunch. No "Save" dialogs unless you explicitly request one
- **Themes** — Dark (default) and Light, switchable via View menu. Persisted across sessions
- **macOS Native Feel** — Hidden inset title bar with traffic lights, system font, keyboard shortcuts
- **Find & Replace** — Built-in search panel (Cmd+F)

## Getting Started

### Prerequisites

- Node.js 18+
- macOS

### Install & Run

```bash
npm install
npm start
```

### Build DMG

```bash
npm run build
```

The DMG installer will be created in the `dist/` directory.

## Project Structure

```
domaspad/
  main.js           Electron main process
  preload.js        IPC bridge (main ↔ renderer)
  renderer/
    index.html      App shell
    app.js          Application logic (source — edit this)
    bundle.js       Bundled JS (generated by esbuild — not committed)
    styles.css      Themes and layout
```

## How It Works

DomasPad uses Electron's multi-process architecture:

- **Main process** (`main.js`) manages the window, native menus, file dialogs, and persists session data to `~/Library/Application Support/DomasPad/session.json`
- **Preload** (`preload.js`) exposes a secure API bridge using `contextBridge`
- **Renderer** (`app.js`) handles the tab system, CodeMirror editor instances, theme switching, and auto-save logic

Content is auto-saved 300ms after each edit. On relaunch, all tabs and cursor positions are restored instantly. File-backed tabs are re-read from disk to pick up external changes.
